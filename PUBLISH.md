# Подготовка «Проекта Тани» к GitHub

Текущий прототип «Ключи» публикуется в `glazest-t/keys-mobile-new`: https://glazest-t.github.io/keys-mobile-new/. Отправка выполняется из отдельной Git-копии в `output/github/keys-mobile-new`. Локальные ключи и служебные файлы в Git не входят.

## Что загружать

Архив `output/keys-github-ready.zip` содержит папку `keys-mobile`. Распакуйте её в отдельное место и используйте **содержимое** как корень репозитория. Архив включает скрытые `.github`, `.gitignore` и `.nvmrc` — их тоже нужно загрузить.

Не загружайте ZIP как единственный файл репозитория. Для проекта с медиа используйте Git или GitHub Desktop. В архив не входят `node_modules`, сборки `dist`, промежуточные файлы, скриншоты, резервные копии и содержимое браузерного хранилища.

## Проверка перед отправкой

Установите Node.js 22. В распакованной папке выполните:

```bash
npm ci
npm run check
npm run preview
```

Прототип доступен по адресу http://localhost:4173. `npm run check` создаёт чистую сборку и выполняет тесты. Эталонные файлы тестов находятся внутри `tests/fixtures`; внешние резервные копии не требуются.

## Репозиторий и GitHub Pages

Для существующего `glazest-t/keys-mobile`: клонируйте репозиторий отдельно, перенесите подготовленные файлы в новую ветку, проверьте изменения и затем слейте их в `main`. Не инициализируйте Git в общей папке с соседними проектами.

Для нового репозитория: создайте пустой репозиторий и добавьте распакованную папку через GitHub Desktop или Git.

В **Settings → Pages → Build and deployment** выберите **GitHub Actions**. Workflow `.github/workflows/deploy-pages.yml` при отправке в `main` устанавливает зависимости через `npm ci`, собирает сайт, запускает тесты и публикует `dist`. Также доступен ручной запуск **Actions → Deploy GitHub Pages → Run workflow**.

Для проверки pull request предусмотрен отдельный workflow без публикации. До отправки изменений на GitHub никакие удалённые действия не выполняются.

## Сценарии

К адресу сайта можно добавить:

- `?scenario=search` — брони ещё нет.
- `?scenario=booked&arrivalDay=day-8` — за 8 дней до заезда.
- `?scenario=booked&arrivalDay=day-3` — за 3 дня до заезда.
- `?scenario=booked&arrivalDay=arrival` — день заезда.
- `?scenario=stay&stayDay=day-1` — первый день проживания.
- `?scenario=stay&stayDay=day-2` — второй день проживания.
- `?scenario=stay&stayDay=checkout` — день выезда.
- `?scenario=after` — поездка завершена.

Все пути сборки относительные, для размещения в подкаталоге GitHub Pages. Основные медиа и шрифты включены в проект. Часть карт, изображений и библиотека Lucide используют внешние URL и требуют интернета. Прототип сохраняет демонстрационные данные локально в браузере и не требует серверных секретов.

Повторное создание архива: `npm run export:github` (нужен Python 3).

### Карты 2ГИС

Для карт MapGL добавьте GitHub Actions secret `KEYS_2GIS_API_KEY` до публикации. Без ключа сборка сохраняет прежние карты. Подробнее: [настройка 2ГИС](design/2gis-integration.md).
