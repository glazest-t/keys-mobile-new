# Ключи — интерактивный прототип

Статический прототип «Ключи», рабочая версия «Проект Тани». Требуется Node.js 22 и npm. Исходники автономны: соседние папки и локальные резервные копии для сборки не нужны.

Актуальная подготовка к GitHub: [PUBLISH.md](PUBLISH.md). Для проверки сборки и сценариев: `npm run check`. Архив исходников: `npm run export:github` (Python 3).

В приложение входят все сценарии поездки, «Найти», «Чаты», «Выгоды», профиль, избранные отели и уведомления. Каталог и операции работают на локальных демонстрационных данных; состояние сохраняется в браузере. Реальные платежи и бронирования не выполняются.

Ниже инструкции по запуску и исторические заметки разработки; текущие исходники имеют приоритет над описаниями ранних версий.

## Локальная сборка

```bash
npm ci
npm run build
npm test
```

Готовый сайт появится в каталоге `dist`.

## Локальный просмотр

```bash
npm run preview
```

После запуска откройте `http://localhost:4173`.

## Публикация на GitHub Pages

1. Создайте репозиторий и поместите содержимое этой папки в его корень.
2. В настройках репозитория откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **GitHub Actions**.
4. Отправьте изменения в ветку `main`. Сценарий публикации запустится автоматически.

## Оформление из UI kit Арбаны — 29 сентября 2026

По прямому поручению пользователя к рабочей версии в папке «Проект Тани» применён UI kit Арбаны. Это по-прежнему базовый прототип «Ключей»: Maidens Hotel, номер 412, счёт 480 ₽, прежние экраны, данные, сценарии и переходы.

- Навигация: «Поездки / Найти / Чаты / Выгоды». Профиль доступен через аватар.
- Golos Text Variable и исходные токены Арбаны: `src/arbana/tokens.css`, локальные шрифты `src/arbana/assets/`.
- Визуальная адаптация: `src/arbana/adapter.css`; исходная палитра экранов преобразуется в токены сборщиком `scripts/arbana-theme.mjs`.
- SVG-иконки из UI kit: `src/arbana/icons.js`. Этот слой не меняет маршруты, обработчики действий или состояние приложения.
- Сохраняется светлая тема. На мобильных ширинах экран подстраивается под высоту viewport; прокрутка остаётся внутри экрана.
- Исходная разметка и сценарии `src/prototype.html` сохранены. Единственная правка маршрутизации — исправление оставшегося соответствия старого названия «Ассистент», чтобы ранее переименованный пункт «Чаты» открывал исходный раздел.

До изменений создана полная копия исходников и сборки. Точный путь записан в `design/migration-baseline.json`.

Сборка: `npm run build`. Проверка сохранения логики: `node scripts/verify-preservation.mjs`. Отчёт: `design/verification.json`. Проверка сравнивает все 67 исходных встроенных скриптов с сохранённой версией и допускает только указанное исправление названия в маршрутизации.

В браузере проверены ключ до успешного открытия, заказ еды с корзиной, поиск и детали отеля, отправка вопроса ассистенту, правила лояльности, доступ к профилю, добавление билета, отправка отзыва, маршрут и меню поделиться. Проверена мобильная ширина 375 px. Полный перебор всех сочетаний состояний не выполнялся; исходные демо-ограничения прототипа остаются.

`keys-github-pages/`, исходная Арбана и UI kit не изменялись. Публикация не выполнялась.

## Найти и Чаты из Арбаны — 29 сентября 2026

По следующему прямому запросу пользователя эти два раздела теперь используют исходные React-компоненты, reducer, провайдеры и локальный API Арбаны. Это функциональная миграция, которая заменяет прежние разделы поиска и ассистента; описание выше относится к предыдущему этапу визуальной адаптации.

Перенесены каталог, поиск по городу/отелю, даты и гости, фильтры и сортировка, фото и карта, карточки/номера/тарифы, избранное, цены, лента, друзья и совместные подборки, помощник с историей, бронирование/оплата/подтверждение, список чатов, новые диалоги, поиск, черновики, ответы и передача сотруднику. Фото, видео и шрифты локальны. Демо-ответы, оплаты и карта сохраняют ограничения автономной Арбаны.

- `vendor/arbana/` — зафиксированная копия источника и его сборщика, независимая от соседней папки Арбаны.
- `scripts/build-sections.mjs` — воспроизводимая сборка исходного приложения и проверяемые точечные адаптации интеграции.
- `src/sections/runtime-adapter.js` — контейнер экранов, связь с навигацией «Ключей» и контекст Maidens Hotel.
- `src/sections/host.js` — переключение разделов; один постоянный iframe сохраняет общее состояние поиска и чатов при переходах. Изоляция защищает CSS и обработчики базового прототипа от глобальных стилей React-приложения. Это локальная часть сборки, внешних сайтов и серверов она не требует.
- `src/sections/frame.css`, `host.css` — размеры экрана и мобильная прокрутка.
- `dist/sections/` — готовый автономный модуль. Публиковать/передавать нужно весь `dist`.

Главная, цифровой ключ 412, активное проживание Maidens Hotel, услуги, маршрут, выгоды и профиль остаются из проекта Тани. Из новой навигации «Поездки», «Выгоды» и аватар возвращают в исходные разделы. Чат Maidens получает правильные даты, гостя и сведения о завтраке. Ссылка на текущую бронь и обращение о проблеме открывают исходные сценарии Тани. Новая подтверждённая демо-бронь доступна карточкой на главной; она не подменяет текущее проживание.

Состояние поиска, диалогов и новой демо-брони сохраняется при переключении вкладок в рамках открытого прототипа. Как и в исходной Арбане, перезагрузка запускает сценарий заново; данные локального аккаунта, включая избранное, сохраняются. Для них используется отдельный ключ `keys-arbana-sections-v1`.

Проверки: `npm run build`, затем `npm test`. Оригинальные проверки: `node --test vendor/arbana/tests/prototype.test.mjs`. Проверка сохранности исходного прототипа продолжает сравнивать все его встроенные скрипты; отдельные тесты проверяют новые сценарии и связь с оболочкой. Резервная копия до переноса указана в `design/sections-migration.json`. Исходная Арбана и опубликованный сайт не изменялись.

## Единая шапка

Основные разделы «Поездки / Найти / Чаты / Выгоды» и профиль используют общий компонент `src/arbana/app-header.js` и единый `app-header.css`: логотип, уведомления и профиль с одинаковыми размерами и отступами. React-разделы используют ту же разметку. Колокольчик на главной, в выгодах и профиле открывает общий центр уведомлений; «Назад» возвращает к исходному разделу. На вложенных экранах сохранены их заголовки, возврат и действия; декоративная строка времени убрана, круглые кнопки приведены к стилю Арбаны. Приветствие, город и дата поездки остаются в содержимом главной.

## Единое нижнее меню

`src/arbana/app-nav.js` задаёт общие пункты, подписи и SVG-иконки, `app-nav.css` — одну геометрию и оформление панели для исходных экранов и React-разделов. Существующие кнопки базового прототипа сохраняют обработчики и атрибуты переходов; динамически создаваемые меню получают то же оформление. Встроенный модуль использует тот же набор пунктов и передаёт состояние индикатора непрочитанных чатов оболочке. На вложенных экранах сохранены прежние условия показа меню.

## Главная текущего проживания

По запросу пользователя главная перестроена в `src/home/home.js` и `home.css`: компактный отель и статус, календарная лента дат заезда и выезда с выделенным сегодняшним днём (сейчас день 2 из 7), исходный цифровой ключ от номера 412, депозит, Wi-Fi, завтрак, каталог услуг, помощь и места по интересам. Рядом с названием отеля расположена явная кнопка «Детали брони». Приветствие и большая карточка отеля скрыты. Исходные элементы остаются скрытыми точками интеграции со сценариями базового прототипа.

Подтверждённые пользователем демо-данные счёта: 10 000 ₽ внесено, 480 ₽ расходов, 9 520 ₽ остаток. Wi-Fi показывает известные сеть и логин, а пароль — демонстрационный, с соответствующей подписью. Для мест использованы существующие рекомендации поездки; открываются карточки и ссылки на карту. Это фиксированный демо-сценарий предпочтений, не новая серверная рекомендательная система. Завтрак LEA, 3 этаж, 07:00–12:00, не включён в тариф, 680 ₽ с Silver.

В браузере проверены детали депозита, показ пароля, завтрак → каталог услуг, помощь → возврат на главную, места → карточка → возврат, цифровой ключ → подтверждение, мобильная ширина 375 px. Главная собирается независимо от React-разделов; текущий `dist/home` обновлён из исходников без повторного копирования неизменённых медиа. `npm test` проверяет сценарии и сохранение 67 исходных встроенных скриптов.

Текущая главная использует композицию карточки проживания: синий блок с номером, текущим днём, датами и ключом; быстрые действия; общая карточка депозита и завтрака; отдельные места по интересам. Анализ просмотренных референсов и принятые решения: `design/home-reference-analysis.md`. Токены Арбаны, общая шапка, нижнее меню и обработчики сценариев сохранены.

Её исходники сохранены в `src/home/variants/calendar/` и копируются вместе с остальными файлами главной. `build.mjs` формирует обе HTML-страницы. Текущая локальная сборка обновлена только в части главной, без повторного копирования неизменённых медиа.

### Типографика главной — UI kit Арбаны

Текущая главная и её детали используют Golos Text, размеры `--text-*`, веса 400/500 и межстрочные интервалы `--leading-normal` / `--leading-tight`. Типографика изолирована от старых глобальных правил для `small` и `p`. На ширине до 639 px применяется масштаб 1.05 из UI kit. Общая шапка и навигация проверены; их единый вид сохранён. Проверка: `design/home-typography-verification.json`.

### Нижнее меню — оригинальный вид и движение Арбаны

Общий `src/arbana/app-nav.css/js` воспроизводит `AH`, `glass` и `glass-cap` исходной Арбаны: панель 58 px, фон #f4f6fab8, белая подложка #ffffffeb, переход 380 мс, отскок иконки 420 мс и нажатие scale(.96). Декоративное состояние синхронизировано между исходными экранами и iframe Найти/Чаты; маршрутизация и подписи сохранены. Учитывается prefers-reduced-motion. Проверка — `design/nav-motion-verification.json`.

### Места рядом: карточки, интересы и карта

`src/home/nearby/nearby.js/css` содержит каталог из пяти мест Москвы, выбор интересов (культура, прогулки, кафе/еда), общий фильтр списка и карты, ограничение пешком до 20 минут, детали места и ссылки на маршруты от Maidens. Интересы сохраняются локально отдельно для подборки мест. Список сортируется по времени пешком от отеля. На карте можно выбрать точку, приблизить карту и показать все места вместе с отелем. При возврате сохраняются вид, фильтры и позиция списка/карты.

Leaflet 1.9.4 сохранён локально с лицензией; тайлы OpenStreetMap требуют подключения к интернету. Фотографии локальные, их источники указаны в `src/home/nearby/photo-sources.json` и в деталях мест. Время дороги и посещения — демонстрационные оценки, не данные маршрутизатора; это отмечено в интерфейсе. Кнопки маршрутов передают координаты отеля и места, а также пеший/транспортный/автомобильный режим в Яндекс Карты. Координаты отеля сверены с официальной страницей контактов.

Проверки: `tests/nearby.test.mjs`, `design/nearby-verification.json`. Соседний проект Арбаны и опубликованная версия не менялись.
