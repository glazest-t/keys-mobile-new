# Карты 2ГИС

Подключено и проверено локально 2 октября 2026 года. Ключ пользователя сохранён в исключённом из Git `.env.local` с правами 0600; обычная сборка автоматически его читает. Публикация подготовлена для `glazest-t/keys-mobile-new` по запросу пользователя.

## Подключение

Нужен ключ для Map Tiles API / MapGL JS API из кабинета 2ГИС. SDK загружается только при открытии карты. В браузере ключ виден пользователю по определению; используйте предназначенный для клиентского приложения ключ с ограничениями доменов и квотами, а не серверный секрет.

Для локальной сборки задайте `KEYS_2GIS_API_KEY` в `.env.local` или в окружении и выполните `npm run check`. Переменная окружения имеет приоритет. В GitHub добавьте Repository secret `KEYS_2GIS_API_KEY` (Settings → Secrets and variables → Actions). Workflow публикации уже передаёт её сборщику. Для собственного светлого стиля можно задать `KEYS_2GIS_STYLE_ID` (локальная переменная окружения / Repository variable). По умолчанию используется стандартная светлая карта 2ГИС.

Доступ должен быть разрешён для используемых адресов: `glazest-t.github.io`, `localhost`, `127.0.0.1`. Точный синтаксис ограничений задаётся в кабинете 2ГИС. Ключ не следует сохранять в отслеживаемых исходниках. Конфигурация генерируется в `dist/maps/config.js`; `dist` исключён из Git.

Пока ключ не задан, сохраняются прежние карты: локальная схема в поиске и Leaflet/OpenStreetMap в «Местах рядом». Неверный заданный ключ не приводит к скрытому переходу на другой сервис: экран показывает ошибку, список остаётся доступен.

## Покрытие

- Карты результатов поиска: свёрнутая/развёрнутая карта, отели и цены, выбор карточки, кластеризация, масштаб и автоподбор области.
- Карты расположения отелей и связанные экраны используют тот же адаптер MapGL.
- «Места рядом»: отель, места, фильтры, выбранная точка, сохранение позиции карты.
- Экран прибытия: ссылка на маршрут в 2ГИС от текущего местоположения. Яндекс Go остаётся отдельным ранее согласованным сценарием такси; географический фон его имитации также подключён к общему провайдеру. На нём показан отель, реальный маршрут без Routing API не вычисляется.
- Ссылки маршрутов из карточек мест передают начало, конец и тип передвижения в 2ГИС. Ссылка календарного варианта главной также открывает 2ГИС.
- Маленькая декоративная иллюстрация карты на главной остаётся иллюстрацией. Неактивные сохранённые экраны базового прототипа не переписываются.

## Реализация и проверки

`src/maps/2gis.js` — загрузчик SDK, создание карты, географические границы, ссылки маршрутов и адаптер для существующих карт React. Он использует публичные методы MapGL (`project`, `unproject`, `fitBounds`, `invalidateSize`, `HtmlMarker`). Перестроение при изменении размеров сохраняет работу свёрнутой карты. Copyright 2ГИС не скрывается.

`scripts/build-maps.mjs` — конфигурация из окружения; `scripts/adapt-2gis.mjs` — подключение при сборке модулей «Найти» и «Чаты» без изменения оригинальной Арбаны. CSP iframe разрешает SDK и сетевые запросы к доменам 2ГИС.

Тесты `tests/maps-2gis.test.mjs` проверяют отсутствие запроса без ключа, общую загрузку SDK/повтор после ошибки, координаты и отступы при fitBounds, события выбора, обновление и уничтожение маркеров, обработку ошибки стиля и ссылки маршрутов. Это проверки с имитацией SDK. Дополнительно реальная загрузка проверена в браузере с ключом пользователя: тайлы, стили, метки и атрибуция 2ГИС видны в поиске и на карте расположения отеля, открываются карточки отелей и мест. Проверен маршрут до отеля и выбор транспорта в ссылках из «Мест рядом». В тестах 49 успешных проверок. Локальный API теперь пропускает только HTTPS-запросы доменов 2ГИС; остальные внешние запросы по-прежнему заблокированы. Изменение покрыто отдельным тестом.

Для GitHub Pages настроен Repository secret `KEYS_2GIS_API_KEY`. Workflow передаёт его сборщику. После обновления сайта нужно проверять загрузку на опубликованном домене. Открытие внешнего мобильного приложения 2ГИС и его доступ к геолокации требуют проверки на устройстве пользователя.
