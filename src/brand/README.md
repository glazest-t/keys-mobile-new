# Варианты оформления «Ключей»

- `?brand=orbit` — брендбук «Орбита» v1.0, октябрь 2026; вариант по умолчанию, в переключателе называется «Базовый» без пометки «В процессе».
- «Орбита New» отклонена пользователем и убрана из переключателя. Её стили и логика компоновки больше не подключаются; ссылки `?brand=orbit-new` и сохранённый выбор переключаются на «Базовый» (`orbit`). Не использовать этот вариант для дальнейшей разработки.
- Прежний исходный дизайн убран из переключателя. Старые ссылки `?brand=base` и сохранённый выбор прежнего варианта открывают актуальный «Базовый» (`orbit`); исходные стили и изображения сохранены.
- Переключатель находится над прототипом, выбор хранится локально. Параметр URL имеет приоритет.
- Одна логика сценариев, авторизации и бронирования; тема синхронизируется с iframe поиска.

Исходные логотипы, иконки и токены предоставлены пользователем в архиве «Брендинг мобильного приложения.zip». Golos Text уже поставляется локально в `src/arbana/assets`.

Экран входа обновлён по `login-export.zip` от 13 октября 2026. Слои SVG и keyframes взяты из предоставленного `login-flow.html` и `splash-animation.css`: ключ → точка на орбите за 2,2 с; с 1,2 с логотип поднимается, с 1,65 с появляется форма. При reduced motion форма доступна сразу.

Телефон — реальное поле с +7 и маской. Кнопка активна при 10 цифрах. Проверка шести цифр запускается автоматически: 1,2 с состояния проверки, затем 0,7 с успеха. Логика прототипа сохранена: код 123456, новый гость вводит имя, зарегистрированный сразу входит. Неверный код и просроченный код не пропускают пользователя; уход со страницы отменяет отложенный переход. Нативная клавиатура устройства, без её имитации в макете.

Визуальные изменения изолированы в `brand.css`, все продуктовые селекторы ограничены `data-keys-brand="orbit"`. Базовый вариант не меняет сценарии. GitHub и резервная копия не обновляются автоматически.
