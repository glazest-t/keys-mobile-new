# Тексты интерфейса Ключей

Основание: предоставленный пользователем документ «Промт по ТОВ Ключей.docx», 28 октября 2026 года. Голос — спокойный консьерж: коротко, понятно, без заискивания, технического жаргона и неподтверждённых обещаний.

`tone-of-voice.mjs` — общий редакторский словарь. `scripts/build-ux-copy.mjs` применяет его к текстам готовой сборки после сборки исходных экранов и интегрированных модулей, до проставления версий ресурсов. Исходный сохранённый прототип и vendor-снимок не переписываются. Это соответствует устройству проекта, в котором старые экраны и новые модули собираются вместе.

Правила:

- «Бронирование», «Заехать раньше», «Остаться дольше»; нейтральные названия «Жильё», «Место проживания» или опущенное существительное. «Объект» только там, где нужен субъект.
- Короткие действия, строчные «вы» и «ваш», обязательная «ё», кавычки «ёлочки», разделитель •, без восклицаний и эмодзи. В заголовках, кнопках и концах подписей нет точек; между самостоятельными предложениями они остаются.
- Цены, суммы, сроки, статусы оплаты и доступность действий не выводятся из редакторских формулировок. Неоплаченное добавление показывается как «Оплата отдельно», а не «Оплачено отдельно». Пример про залог не добавляет депозит в приложение.
- Названия объектов, торговые марки и фактические надписи (например, кнопка «Отель» на домофоне) сохраняются. Тип размещения «Апарт-отель» также остаётся типом, а не общим названием каталога.
- Пользовательские отзывы, сообщения, заметки, введённые данные, контакты и ссылки не редактируются. Старые системные уведомления форматируются только при показе, без перезаписи хранилища.
- Идентификаторы маршрутов и действий, вычисления, операторы, обработчики и числовые значения не заменяются текстовым поиском. Сборка разбирает JavaScript и меняет только строковые значения; HTML разбирается отдельно. Селекторы со старыми текстовыми значениями и соответствующие атрибуты проходят одинаковое преобразование.

Для новых экранов сразу писать согласованные тексты в исходниках. Словарь нужен для единого оформления сохранённых экранов, повторяющихся фраз и сообщений. После правок запускать `npm run check`; проверять мобильный и десктопный виды, длинные кнопки и динамические сочетания числа с существительным.

`node scripts/audit-ux-copy.mjs` создаёт инвентаризацию в `tmp/ux-copy/`. Сборка записывает журнал замен `tmp/ux-copy/build-report.json`. Эти файлы — материалы проверки, не часть интерфейса.
