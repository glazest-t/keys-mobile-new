# Версии прототипа

С 6 ноября 2026 года текущие `src/`, `scripts/` и `build.mjs` — рабочая версия **Ноябрь**. Она открывается по основному адресу прототипа. Все дальнейшие изменения делать здесь.

**Полная** — неизменяемый снимок готового приложения на 6 ноября, после коммита `6090d926daf751915ed20c993da73fbc3ba9a4bb`. Он хранится в `full/site/` со всеми необходимыми ресурсами. `full/manifest.json` фиксирует SHA-256 каждого файла. Не обновлять снимок при дальнейшей разработке.

Сборка проверяет контрольные суммы и копирует снимок в `dist/versions/full/`. В обе версии добавляется общий переключатель «Ноябрь / Полная» на месте прежнего единственного варианта оформления «Базовый». Оформление сохраняется. Переключение сохраняет сценарий, режим просмотра и маршрут. Обе версии используют существующее хранилище демоданных браузера; снимок фиксирует код, а не пользовательские данные.

Единственные дополнения к опубликованной копии снимка: переключатель версии и текущая конфигурация карт из окружения сборки. Локальные ключи не сохранены в снимке. UI kit как отдельная документация не дублируется; все экраны приложения и ресурсы сохранены.

Полная резервная копия исходников до добавления переключателя: `backups/keys-full-2026-11-06-source.zip` (локально, без `.env.local`, зависимостей и сгенерированных файлов).

При публикации обязательно включать каталог `versions/` и `scripts/build-versions.mjs`. `npm run export:github` уже учитывает снимок. Публикация — только по запросу пользователя.
